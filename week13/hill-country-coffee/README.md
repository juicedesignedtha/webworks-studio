# Hill Country Coffee

## WebWorks Studio Client Project

This folder is the **single continuing client project** for the final WebWorks Studio sprints. It contains the supplied client discovery materials and the Week 13 project plan. Continue using this same folder for design, production, quality assurance, and final delivery.

## Client

**Hill Country Coffee**  
An independent regional coffee company based in Central Texas. The website will help customers understand the business, explore its approved drink and food categories, and find practical visit information.

## Week 13 Status

**Sprint:** Client Sprint 1 — Discovery & Planning  
**Role:** Junior Web Designer / Developer

### Current Deliverable

[Open the Hill Country Coffee Client Project Plan](docs/client-project-plan.md)

The plan documents the client goals, supplied personas, user needs, priority tasks, content inventory, requirements, accessibility expectations, MVP scope, sitemap, technical approach, production milestones, risks, and backlog.

**Week 13 is a planning sprint.** Production interface work begins in Week 14. Do not treat this planning deliverable as a production website.

## Project Workflow

1. **Week 13 — Discovery & Planning:** establish goals, users, requirements, content, scope, sitemap, risks, and production direction.
2. **Week 14 — Design + Build:** translate the approved plan into interface decisions and a substantially complete responsive MVP.
3. **Week 15 — QA + Refinement:** test functionality, accessibility, content, responsiveness, and visual consistency; correct issues.
4. **Week 16 — Delivery + Portfolio:** finalize the site, documentation, deployment, presentation, and portfolio/case-study evidence.

## Important

The supplied files in `assets/` are the source of truth for client facts and approved content. Do not invent prices, addresses, phone numbers, business hours, menu details, or policies. Record missing information as a question or dependency until it is confirmed.

Keep the project in this one `hill-country-coffee` folder as it moves through the remaining sprints.
